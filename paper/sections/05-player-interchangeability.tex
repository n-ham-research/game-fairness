\section{Three implementation requirements}
For any of the utility groups $G$, distinguish full player image
$q(G)=S_n$; a section $\sigma:S_n\to G$ with $q\sigma=\id$; and a
strategy-trivial section, whose component at a fixed player is the identity.
These are respectively individual, coherent and matching-based realization.
Matching-based realization implies coherent realization, which implies full
image. Ham's matching results \citep[\S4--5]{ham2021}, in their audited typed
formulation, identify the last requirement with a full strategy matching.
The converse implications fail in companion-project examples.

These distinctions concern transformations, rather than welfare. If selected
lifts $t_p$ implement every requested player permutation and $t_e=1$, typed
path independence is precisely $t_pt_q=t_{pq}$: compare successive requests
$q,p$ with the single request $pq$. This is exactly the section condition.
But two exact histories with the same final player permutation transport each
original focal payoff to the same numerical value. Kernel differences can
change actions while remaining payoff-invisible. External reset costs or
commitments would be additional model data.
